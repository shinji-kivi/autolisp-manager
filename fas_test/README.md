# AGFASTEST 取扱説明書

コンパイル版(.fas)の動作確認用テストコマンドです。
図面には一切変更を加えません。

## コマンド

| コマンド | 内容 |
| --- | --- |
| AGFASTEST | 動作確認用のダイアログを表示します |
| AGFASTEST-HELP | この取扱説明書を表示します |

## 確認したいこと

1. AutoCAD 起動時に自動でロードされるか
2. AGFASTEST コマンドが実行できるか
3. AGFASTEST-HELP でこの説明書が表示されるか

この 3 つがコンパイル版(.fas)でも通れば、
AutoLISP 管理ツールのコンパイル版対応を本実装に進めます。
